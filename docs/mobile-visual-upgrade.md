# Мобильный редизайн Aegis Arena

Дата: 7 сентября 2026. Реализован в текущем Next.js-приложении и Android WebView.

## Реализованный план

1. Узнаваемость: собственный логотип Aegis Arena, знак Dota 2 в шапке, официальная иллюстрация с героями на главной.
2. Главная гостя: вход через Steam, переход к кубкам и командам, реальные открытые турниры из базы. Главная игрока сохраняет его следующий шаг и получает компактную обложку.
3. Рабочие страницы: игровая сцена с регулируемой выраженностью. В админке и трансляционных оверлеях фон отключён.
4. Навигация: пять вкладок, отдельные наборы для гостя, игрока и организатора. Активная вкладка выделяется бирюзовым, основное действие сохраняет золотой акцент.
5. Движение: появление и медленное приближение обложки, движение сцены, отклик иконок и кнопок. Системная настройка `prefers-reduced-motion` отключает CSS-движение; движение оформления также выключается в админке.
6. Мобильная эргономика: сенсорные зоны 44–48 px, поля от 16 px, нижний системный отступ, перенос длинных надписей.

## Редактор

Адрес: `/admin/appearance`. На телефоне: панель организатора → «Ещё» → «Оформление». На desktop доступна отдельная вкладка.

Редактируются обложка главной, логотип Aegis Arena, знак Dota 2 и фоновая сцена. Для каждого изображения доступны URL, папка и S3. Дополнительно доступны движение, выразительность фона и вертикальный центр кадра.

Загрузка меняет черновик. Кнопка «Сохранить оформление» публикует все поля вместе. Другие изменения черновика при загрузке сохраняются; повторный выбор того же файла поддерживается. Сброс стандартного оформления требует подтверждения и сразу применяется.

Предпросмотр использует реальный компонент обложки. Редактор меняет веб-интерфейс, в том числе внутри APK. Иконка запуска и нативный splash входят в Android-сборку и не заменяются этим редактором.

## Хранение

Настройки: таблица `SiteAppearance`, строка `primary`. Миграция: `20260907150000_site_appearance`. При отсутствии настроек используются встроенные значения.

Локальные загрузки: `.data/media/appearance/`. Корень меняется через `LOCAL_MEDIA_DIR`. В development папка сохраняется в bind mount проекта; в `docker-compose.prod.yml` добавлен постоянный volume `appearance-media`.

S3 использует существующие `S3_ENDPOINT`, `S3_REGION`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`. При отсутствии конфигурации этот вариант выключен. Проверено фактической загрузкой в локальный MinIO.

Файлы обоих хранилищ выдаются через `/api/media/appearance/{local|s3}/appearance/...`. Бакет можно оставлять закрытым; клиент не получает ключи доступа или внутренний адрес MinIO.

| Метод и адрес | Поведение |
| --- | --- |
| `GET /api/admin/appearance` | Настройки, значения по умолчанию, доступность S3 |
| `PATCH /api/admin/appearance` | Проверка и публикация переданных полей |
| `DELETE /api/admin/appearance` | Восстановление стандартного оформления |
| `POST /api/admin/appearance/upload` | Multipart: `field`, `storage`, `file`; возвращает URL черновика |
| `GET /api/media/appearance/{storage}/{...path}` | Выдача изображения по уникальному URL |

Админ-операции проверяют сессию и права. Изменения требуют совпадения browser origin, включая порт `3002`. Сохранение и аудит выполняются одной транзакцией. Размер тела ограничен до чтения всего запроса, в том числе без `Content-Length`.

Загрузки ограничены 10 МБ и 24 мегапикселями. Сервер декодирует изображение и сохраняет WebP без метаданных. Логотипы уменьшаются до 512 px, широкие изображения до 1920 px. Многокадровые файлы сохраняются первым кадром; контролируемое движение добавляет интерфейс. SVG не принимается.

Для URL принимаются HTTPS или внутренний путь. HTTP разрешён только для loopback-разработки. Внешние URL загружаются браузером, сервер их не скачивает. Сбой изображения на главной или в основной шапке включает локальный резерв.

Загруженные, но неопубликованные файлы остаются в хранилище. Автоматическая очистка старых медиа не добавлялась; её следует строить по ссылкам и сроку хранения, сохраняя возможность возврата.

## Исправления

- Каталог команд мог ждать OpenDota больше минуты. Внешние запросы аналитики имеют общий deadline; каталог использует 3 секунды и показывает команды без недоступной статистики.
- Повторный выбор того же файла для другого хранилища мог не вызвать событие выбора. Поле очищается после чтения, выбранный файл остаётся в черновике.
- Служебный индикатор Next.js перекрывал первую нижнюю вкладку на стенде. Он отключён.
- Раздел оформления добавлен в активное состояние вкладки «Ещё».

## Проверка

- 230 модульных тестов в 66 файлах прошли; после исправления deadline отдельно прошёл дополнительный тест отмены пяти внешних запросов. Всего 231 проверка в 67 файлах.
- `npm run build` завершился успешно, включая TypeScript. Host-сборка сообщала о недоступности Docker-имён `redis2` и `postgres2`, но не остановилась. База и хранилища проверены отдельно на Docker-стенде.
- Playwright: 13 сценариев прошли, пять дублирующих админ-прогонов пропущены. Матрица: Chromium 393×852 и 360×800, WebKit iPhone 15 / SE / Pro Max, desktop 1440×1000.
- Проверены арт, отсутствие горизонтальной прокрутки, нижняя навигация, reduced motion, запрет гостевого доступа, неверный origin, повреждённый файл, URL, папка, MinIO/S3, черновик, публикация и сброс.
- Админ-тест создаёт временную локальную сессию, восстанавливает прежнее оформление и удаляет свою сессию.
- Android: `assembleDebug lintDebug` прошли. APK установлен с сохранением данных, cold start успешен. Скриншот настоящего WebView: `android/build/aegis-upgrade-home.png`.
- WebKit на Windows не заменяет настоящий Safari/iPhone. Камера физического устройства, полноценный вход в реальный Steam и production release signing в этот прогон не входили.

## Повторный запуск

Стенд: `http://localhost:3002/home`. Редактор: `http://localhost:3002/admin/appearance`.

```powershell
npm.cmd test
npm.cmd run test:e2e
```

Локальный админ-прогон:

```powershell
$env:AEGIS_E2E_ADMIN = '1'
npx.cmd playwright test
```

Тест ожидает PostgreSQL на `5434`, сайт на `3002` и существующего администратора стенда. Прежнее оформление восстанавливается после теста.

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

SHA-256: `B6153914BC0D06317FE43078A6EA8F3C574F092BF547C512133B09473F9DF79E`.
